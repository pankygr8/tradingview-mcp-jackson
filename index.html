How to read this

Edge score = uniform-plan expectancy (R per trade) × n/(n+30); it is the one number that compares scanners on identical trade rules. EDGE needs ≥20 trades, edge score > 0.08R and t-stat > 2 on the primary return. Native columns use each scanner's own entry/stop/TP1 (swing, intraday, momentum only). Stop-first is assumed when a bar touches both levels. Replay results carry survivorship bias (today's index members) and should be confirmed by live results before sizing up.
